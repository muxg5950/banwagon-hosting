## 搬瓦工是什么？一句话说清楚

搬瓦工（BandwagonHost，简称 BWG）是加拿大 IT7 Networks 旗下的 VPS 服务品牌，成立于 2012 年，主打对中国大陆优化的网络线路。它的中文名来自英文发音"Ban Wa Gong"的谐音，叫着顺口，国内技术社区里用的人相当多。

简单说：你花一笔钱，买一台在海外数据中心运行的虚拟服务器，完全归你管理，搬瓦工只负责把机器跑起来，配置维护是你自己的事。正因为这种"自托管"模式，价格比托管云服务便宜很多。

搬瓦工目前的核心优势是 CN2 GIA 线路——这是电信直连优化线路，国内访问延迟普遍在 130-160ms 之间，晚高峰稳定性相对普通线路明显更好。

## 搬瓦工注册购买教程：一步一步来

整个购买流程大概 5-10 分钟，分四步走。

**第一步：选套餐，进购买页面**

直接从本文的套餐链接点进去，页面会显示当前这个套餐的配置详情。找到 Billing Cycle（计费周期）选择月付/季付/年付——年付最划算，但 CN2 GIA-E 系列最低只能季付。Location（机房位置）新手不纠结，CN2 GIA-E 系列默认选 DC6 CN2 GIA-E 就行，之后在后台随时可以免费切换机房。

选完之后点击页面底部的 **Add to Cart**（加入购物车）。

**第二步：填优惠码**

进入购物车页面之后，找到 **Promotional Code** 输入框，把优惠码填进去，点击 **Validate Code** 验证。验证成功会看到折扣金额变化。

**第三步：注册账户并填写信息**

点击 **Checkout** 进入结账页面。如果已有账号直接点 "Click here to login" 登录。

新用户填写注册信息注意两点：

- **Country 必须选 China（中国）**，选其他国家会被系统判定为欺诈，订单很可能被取消
- **不要挂代理**，注册时使用真实 IP，否则同样可能触发风控
- 邮箱填写务必准确，之后的 VPS 初始密码、SSH 信息都会发到这个邮箱

**第四步：支付宝付款**

付款方式选 **Alipay（支付宝）**，勾选同意服务条款，点击 **Complete Order**。页面跳转到支付宝付款界面，手机扫码完成付款。

付款成功后搬瓦工发一封邮件到注册邮箱，包含 VPS 的 IP 地址、SSH 端口和 root 初始密码。登录后台 `Services → My Services → KiwiVM Control Panel` 就可以管理你的机器了。
